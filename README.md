# DESKtab

Painel de mesa para tablet Android antigo (Samsung Tab A). Um arquivo só (`index.html`), sem dependências.

Telas (arraste para o lado):
1. Relógio tech + controle do Spotify
2. Porta-retrato + controle do Spotify
3. Casa (Home Assistant)
4. Trabalho (Pomodoro + tarefas)

## Configurar
- **Spotify (Premium):** crie um app em developer.spotify.com, cadastre o endereço desta página como *Redirect URI* e cole o Client ID na engrenagem ⚙.
- **Home Assistant:** endereço, token de longa duração e uma linha por dispositivo (`light.sala | Luz da sala`).
- No tablet: Chrome → menu → *Adicionar à tela inicial*. Para a tela não apagar, ative "manter tela ligada" (Opções do desenvolvedor → Permanecer ativo, com o carregador).

Configurações, fotos e tarefas ficam salvas só no tablet.
